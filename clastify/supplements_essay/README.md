# 顶级大学补充文书知识库 (2026)

## 📚 项目概述

本知识库汇总了 US News Top 50 中 23 所顶级大学的补充文书写作指南和真实样本分析，基于 Clastify 的 200+ 真实学生文书数据（已验证录取结果）。

**核心价值：**
- 理解每所学校补充文书的核心考察点
- 对比成功 vs 失败文书的具体差异
- 学习跨校共同的成功模式
- 获得学校特定的写作策略

## 💡 核心发现（跨校共同特征）

### 成功文书的 4 大特征
1. **具体性** — 一个真实故事 > 十个泛泛的品质陈述
2. **成长 vs 成就** — "我学到了什么" > "我完成了什么"
3. **真实声音** — 有性格、有时"书呆气"、充满热情 > 完美但无趣
4. **对学校的真实理解** — 具体课程/教授/资源 > "我想进你们学校"

### 失败文书的 4 大陷阱
1. **通用化** — 可改个学校名字用于其他大学
2. **缺乏深度** — "我热爱科学" vs "我对拓扑几何的对称性感兴趣"
3. **反向关注** — 题问"你如何"答成"学校如何帮助我"
4. **不自然** — 显得在迎合想象中的"完美申请者"

## 🔍 如何使用本知识库

### 对于申请者
1. **选择目标学校** → 查看对应文件
2. **了解结构** → 读懂该校的 prompt 要求
3. **学习策略** → 查看"成功要素"和"常见失败点"
4. **深入研究** → 按文件指导登录 Clastify，查看 200+ 真实样本
5. **对比分析** → 在 Clastify 中对比录取 vs 未录取文书
6. **应用策略** → 基于学习到的模式，结合自己的故事写作

### 对于教师/顾问
1. **理解学校差异** — 每所学校的补充文书哲学
2. **指导学生** — 基于学校特定的写作要点
3. **展示样本** — 使用 Clastify 数据展示成功 vs 失败
4. **制定策略** — 为学生定制化的写作计划
5. **跟踪进度** — 使用知识库的框架评估学生文书

## 🌐 Clastify 数据访问

本知识库中的所有数据来源于 **Clastify**（https://www.clastify.com），一个真实的学生补充文书数据库：

**如何访问：**
1. 登录 clastify.com
2. 找到目标大学（如 https://www.clastify.com/supplement/harvard-university）
3. 按"录取/未录取"筛选
4. 对比文书和录取结果
5. 按 SAT/专业/申请年份进一步筛选

**关键优势：**
- 真实的学生文书（不是范文编写）
- 真实的录取结果验证
- 200+ 样本数据
- 可按多个维度筛选

## 📌 使用建议

### ✅ 推荐做法
- 浏览 2-3 个目标学校的 Clastify 页面
- 对比录取 vs 未录取文书，寻找模式
- 学习每所学校的特色考察点
- 根据学校特色调整自己的文书
- 请导师按照知识库的框架评估你的文书

### ❌ 避免做法
- 直接复制或模仿样本文书
- 写通用的、可以适用于多所大学的文书
- 忽视学校的特定要求和特色
- 过度关注学校排名而忽视文书内涵
